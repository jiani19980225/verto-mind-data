# Verto Mind — card data

The wisdom-card library the Verto Mind app loads at runtime. Data only: this
repository holds no application code, no ranking logic, and no source corpus.

It exists as a separate public repository because the main repository is private,
and a private raw URL returns 404 to every unauthenticated client — which is
every phone running the app.

## Files

| File | What it is |
|---|---|
| `manifest.json` | Version, counts and sha256 of the payloads. **Fetch this first.** |
| `cards.json` | Serving cards plus the crisis row, as a flat JSON array. |
| `keyword_dict.json` | Classifier vocabulary and safety triggers. |

## Downloading

`cards.json` is ~21 MB (~4.7 MB gzipped, which is what the CDN actually sends).
Do not re-download it on every launch. Fetch `manifest.json` — a few hundred
bytes — compare its `sha256` with the copy you already have, and pull the
payload only when it changed.

```
https://raw.githubusercontent.com/jiani19980225/verto-mind-data/main/manifest.json
https://raw.githubusercontent.com/jiani19980225/verto-mind-data/main/cards.json
https://raw.githubusercontent.com/jiani19980225/verto-mind-data/main/keyword_dict.json
```

## Card shape

A flat array of objects whose keys are the card columns. Every value is a
string; absent data is an empty string, never `null`. Clients should decode
unknown keys leniently — columns get added.

Filter for serving cards the same way the library does:

```
Quote_Status == "solid"  &&  Retired != "TRUE"  &&  Safety_Route == "normal"
```

**`cards.json` also contains one row with `Safety_Route == "crisis"`.** It is not
a wisdom card and it will not pass the filter above — that is deliberate. It is
the crisis-resource response, routed to when input trips the safety tier. Keep
it; dropping it removes the app's safety route.

`Quote_Provenance` says whether the quotation is the source's own words
(`verbatim`) or a modern rendering written for this app (`verto-rendering`).
A rendering must be labelled as one and must never be presented as a published
or public-domain translation, or attributed to a translator.
